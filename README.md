# Unleasher Z
An application created for gamers by a gamer. This app uses root privilege to adjust device performance, mock device info, unlock locked features of games, and many more.

Note: For this applicatioin to work the device must be rooted via Magisk as it uses Magisk Modules to manipulate the system of the device.

BE MINDFUL OF EVERY TWEAKS THAT YOU ENABLE!!



Note:

-Use magisk version 21.4 and above only as it is bugged in lower version than 21.4(Google Apps Not Working Properly).

-Grant Superuser Access when prompted

-Conflict to some gaming modules(depending on the settings that you prefer to use)

-Conflict to Game Unlocker

-This only includes Prop edits just in a fancy manner.

-Performance varries from device s to devices and roms to roms. (Meaning if it doesn't perform well on your device means it will also not perform well to the other devices)

-Use Ultra Mode at your own risk (My device itself can't handle it)

Features:

-Automatic installation of extension module

-Auto Reboot after changing settings.

-A very straight forward and user friendly application

-Unlocking fps and graphics on some games (In beta we only included mobile legends and call of duty mobile, setting max fps doesn't mean it will really goes to the highest still device specs matters.)

-Gaming Presets

-Customization of desired Settings

-Uninstalling app will also uninstall all the codes and scripts that are used to make the app work so no need to worry I already cleaned the mess for you guys.
